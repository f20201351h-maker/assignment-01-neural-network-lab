So nonlinear layers let a network bend space. But what do all those numbers inside a network end up meaning? Let's give a network some words and see what it builds.

EXPERIMENT 03
“What can the model learn inside those numbers?”

Embeddings learn similarity from nothing but next-token prediction.

I made up a tiny language: … words, … sentences. The model's only job is the language-model job: look at a word, guess the next one. Each word gets a list of … numbers — its embedding — and that list is all the model has to guess with. Nobody ever tells it which words are animals.

IT FOUND THE GROUPSAfter training, … content words have a nearest neighbour from their own group (it was … at the random start). Words that are followed by the same things end up with similar numbers. Look closely: cow sits a little apart from cat, dog and horse — in this language cows never chase anything, so what comes after “cow” is different.
THE CONTROLSame words, same counts, same model — but shuffled into random order. No grammar means no context to learn from: only …. So the groups come from context, not from the words themselves.
THE HONEST “MISTAKE”… That's not a bug: in this language both are followed by the / a. A model that only predicts the next word should call them similar. (And it's a toy language — it shows prediction can build structure, not that it understands animals.)
Every model so far nailed its training data — the ReLU stack even hit …. But here's the uncomfortable question: is fitting the training data the same as learning the real pattern?
